# MP3Lint
An mp3 linter for jellyfin music libraries.

## Features

Nothing really worthwhile as of now, currently in active development. Once I figure out taglib you can expect more from MP3Lint.

1. Built-in directory viewer
2. Directory scan + file classification

## Roadmap

* Directory structure linting
* ID3 tag editor
* MusicBrainz tag lookup
* Cover art cropping/aspect ratio linting
